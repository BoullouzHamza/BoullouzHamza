## Hamza Boullouz

PhD candidate in applied mathematics, UM6P (Morocco) & Université Le Havre Normandie (France).

I work on numerical methods for flow in porous media, from discretization to parallel implementation, with applications to composite manufacturing. My current focus is the coupling of these solvers with scientific machine learning.

### Research

- **Finite-volume methods.** Parallel 3D solver on unstructured meshes for particle-laden flow in anisotropic fibrous media; the predicted flow front stays within 3 % of experimental measurements. Part of [Manapy](https://github.com/imadki/manapy), an MPI-parallel finite-volume code.
- **High-performance computing.** Distributed-memory simulations with MPI on HPC clusters, with direct and preconditioned Krylov solvers (MUMPS, PETSc) for the elliptic pressure equation.
- **Scientific machine learning.** Operator learning (DeepONet) as a fast surrogate for the inverse design of injection conditions; physics-informed neural networks for moving-front problems.
