## Hamza Boullouz

PhD candidate in applied mathematics, UM6P (Morocco) & Université Le Havre Normandie (France). Defense: 7 December 2026.

I work on numerical methods for flow in porous media, from discretization to parallel implementation, with applications to composite manufacturing. My current focus is the coupling of these solvers with scientific machine learning.

### Research

- **Finite-volume methods.** Parallel 3D solver on unstructured meshes for particle-laden flow in anisotropic fibrous media; the predicted flow front stays within 3 % of experimental measurements. Part of [Manapy](https://github.com/imadki/manapy), an MPI-parallel finite-volume code.
- **High-performance computing.** Distributed-memory simulations with MPI on HPC clusters, with direct and preconditioned Krylov solvers (MUMPS, PETSc) for the pressure system.
- **Scientific machine learning.** Operator learning (DeepONet) as a fast surrogate for the inverse design of injection conditions; physics-informed neural networks for moving-front problems.

## Hi, I'm Hamza 👋

I'm a PhD candidate in applied mathematics (UM6P, Morocco & Université Le Havre Normandie, France), defending on 7 December 2026. I build numerical solvers for resin flow in fibrous media, the physics behind composite manufacturing processes such as RTM/LCM.

### What I work on

- **Finite-volume solvers.** I developed a parallel 3D solver on unstructured meshes for resin and particle flow in anisotropic fibrous preforms, with VOF front tracking and a full permeability tensor. It is part of [Manapy](https://github.com/imadki/manapy), the parallel finite-volume code I co-develop with my team.
- **High-performance computing.** MPI, parallel linear solvers (MUMPS, PETSc) and strong-scaling studies on HPC clusters.
- **Scientific machine learning.** A DeepONet surrogate coupled with an optimizer to design injection profiles, and a physics-informed neural network (PINN) for mold filling.
